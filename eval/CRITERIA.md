# 내보낼 기준 (실험 전에 먼저 적음 — 2026-11-09)

고른 문제: **P1. 짧게 물은 질문에 너무 긴 답** (모으기 46턴 중 40턴이 350자 초과, 중앙값 547자)

바꿀 것은 한 가지: 시스템 프롬프트에 **답 길이 지침**만 더한다(v1 → v2). 화면 표시(마크다운)·사이트 기능 안내·사이트 수치는 이번에 건드리지 않는다.

## 데이터셋 (`eval/dataset.json`)
- 문제 항목 14개: 모으기에서 길게 답한 질문 그대로 (한국어 11, 영어 1, 중국어 1, 프랑스어 1)
- 정상 항목 10개: 자세한 설명이 필요한 질문 2, 사실 1, 부모 설명 1, 정정 1, 엉뚱한 부탁 2, 프롬프트 빼내기 1, 다른 언어 2
- 항목마다 2번씩 보낸다(LLM 답은 매번 달라서).

## 통과 조건
- 문제 항목: 한·중·일 300자 이하 / 라틴 문자 600자 이하 **그리고** 핵심어(`must`)가 들어 있음
  - 예: 「태양은 왜 뜨거워?」 → 300자 이하이고 `핵융합|수소|헬륨` 중 하나
- 정상 항목: `must` 모두, `mustNot` 없음, `minLen`(자세히 요청한 질문 400자 이상), `script`(답 언어)
  - 예: 「케플러 제3법칙을 자세히」 → 400자 이상이고 `제곱`·`세제곱`이 있음

## 내보낼 기준 (셋 다 만족해야 v2를 배포)
1. 문제 항목 통과율 **80% 이상**
2. 정상 항목 통과율 **90% 이상, 그리고 v1보다 낮지 않음**
3. 답 지연 중앙값이 **v1보다 길지 않음**
